# Week 1 Python Assessment Project

This repository contains the tasks I worked on for my Week 1 Python and Data Engineering assessment.

## Tasks Completed

**Task 1 - Python Basics**

Practiced functions, classes, inheritance, exception handling, and working with employee data.

**Task 2 - File Handling and API**

Read employee details from a CSV file, converted the data into JSON, filtered employees based on salary, and fetched user details from an API.

**Task 3 - Data Analysis**

Used NumPy and Pandas to work with employee data. Practiced handling missing values, removing duplicates, grouping data, joining tables, and creating charts.

**Task 4 - Git and Jupyter Notebook**

Worked with a Jupyter Notebook for employee analysis and used Git to track changes in the project.

## How to Run

1. Open the project folder in VS Code.
2. Create a virtual environment using `py -m venv .venv`.
3. Activate it using `.\.venv\Scripts\Activate.ps1`.
4. Install the packages using `python -m pip install -r requirements.txt`.
5. Run the Python files from the project folder.

To run the tasks:

- `python "Task 1/main.py"`
- `python "Task 2/main.py"`
- `python "Task 3/main.py"`

The Jupyter Notebook is available in the `notebooks` folder.
